## Information

ระบบบริหารจัดการและติดตามการผลิต เป็นระบบ ERP ย่อม ๆ สำหรับการผลิตในอุตสาหกรรม SMEs รายย่อย เริ่มพัฒนาตั้งแต่ปี 2564 จากการสนับสนุนของศูนย์ส่งเสริมอุตสาหกรรมภาคที่ 11 และมหาวิทยาลัยสงขลานครินทร์ โดยเริ่มทดลองใช้ในอุตสาหกรรมบนอำเภอหาดใหญ่ จังหวัดสงขลา ระบบมีความครอบคลุมทั้งคลังวัตถุดิบ คลังสินค้า และการติดตามการผลิตในแต่ละขั้นตอน ต่อมาได้ออกแบบให้โปรแกรมสามารถทำงานในอุตสาหกรรมที่หลากหลายยิ่งขึ้น มีสิ่งต่างๆ ในการผลิตเข้ามาเกี่ยวข้องมากขึ้น ไม่ว่าจะเป็นเรื่องของ Bill of Material, การกระจาย Batch, การแยกหรือรวมกิจกรรม และรวมถึงการออกแบบระบบให้มีความยืดหยุ่นต่ออุตสาหกรรมการผลิต และสามารถ Config ระบบให้เหมาะกับการใช้งานได้ สามารถประสบความสำเร็จในการใช้งานในโรงพิมพ์รายหนึ่งในหาดใหญ่

## System Architecture

ในการเริ่มพัฒนาระบบนี้ ระบบถูกออกแบบในแบบ Monolithic บน Node.js และใช้ฐานข้อมูล MongoDB เป็นหลัก ประกอบกับการใช้ React เป็น Frontend ในการพัฒนาระบบหน้าบ้าน แต่ต่อมาเมื่อมีฟีเจอร์ขยายมากขึ้น ตัวระบบไม่สามารถรองรับการผู้ใช้งานจำนวนมาก และความเร็วในการตอบสนองได้ จึงมีการปรับสถาปัตยกรรมระบบให้เป็นแบบ Microservice มีการนำระบบ Queue ต่างๆ มาใช้งาน และนอกจากนี้ ระบบนี้ยังเป็นจุดเริ่มต้นการศึกษาเทคนิคต่างๆ ในการลดปริมาณการใช้เวลา ทั้งการทำ Cache, Indexing, ปรับปรุงการ Query รวมถึง Technique ต่างๆ มากมาย ตลอดเวลา 3 ปีในการพัฒนา

และเนื่องด้วยพฤติกรรมที่แตกต่างกันของผู้ใช้งานในแต่ละอุตสาหกรรม ทำให้ระบบต้องมีความยืดหยุ่นสูง หลายๆ อย่างสามารถดำเนินการในแบบ Customization ได้โดยไม่ต้องทำที่โค้ด แต่อย่างไรก็ดี การพัฒนาระบบนี้มีทั้งที่ประสบความสำเร็จ และไม่ประสบความสำเร็จในบางกรณี แต่ก็เป็นบทเรียนที่สำคัญในการพัฒนาทั้งด้านระบบ การทำให้ระบบสามารถพัฒนาต่อโดยคนรุ่นต่อไปได้ และการออกแบบให้รับกับอุตสาหกรรม และการ Digital Transformation ที่เหมาะสม

## Current Status

หลังจากผมได้ออกจากการเป็นนักศึกษา และนักพัฒนาของศูนย์วิศวกรรม ระบบนี้เป็นลิขสิทธิ์ของมหาวิทยาลัยสงขลานครินทร์ โดยศูนย์วิศวกรรมระบบอัตโนมัติอัจฉริยะ คณะวิศวกรรมศาสตร์ รวมถึงมีการถูกนำไปให้บริการโดยบริษัท พีเอสยู อินโนเวทีฟ เอ็นจิเนียร์ริ่ง จำกัด ซึ่งเป็นบริษัทในโครงการของ PSU Holding Company ถ้าหากผู้ใดสนใจ สามารถติดต่อเพื่อขอข้อมูลเพิ่มเติมได้ที่ศูนย์วิศวกรรมหรือบริษัทดังกล่าว
